# MAX Domophone Bot

Бот домофонной службы в MAX: приём заявок жителей, связь с диспетчером, справочная информация и каталог ключей.

**Стек:** Python · maxapi · SQLite · aiosqlite · Google Sheets · Pillow.

## Возможности

- Пошаговая заявка: тип обращения, адрес, описание, телефон и вложения.
- Несколько диспетчеров, подтверждение/отклонение заявок и переписка с жителем.
- FAQ, сценарии подключения умного домофона и каталог товаров со ссылками в магазин.
- SQLite и опциональный экспорт в Google Sheets.
- Защита от повторных событий и обработка прерываний мастера через меню.

## Запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Указать свой BOT_TOKEN и MAX user ID диспетчеров.
python -m bot.main
```

Формат `DISPATCHERS`: `id:Имя,id:Имя`. Для Google Sheets нужны собственные ID таблицы и отдельный файл сервисного аккаунта; его путь задаётся через окружение. В `deploy/` сохранён пример systemd-службы.

`bot/` — приложение; `data/products.json` и `data/images/` — каталог; `test_bot.py` — существующие проверки. Пользовательские заявки, рабочая БД, логи, таблицы и ключ Google в репозиторий не входят.
